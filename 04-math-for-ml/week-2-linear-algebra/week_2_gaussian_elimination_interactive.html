What is a System of Linear Equations?

A set of equations where we need to find values that satisfy all equations simultaneously.

2a + 3b = 8
a + b = 4

Solution Types

Type Equations Why
Unique Non-singular (det ≠ 0) All equations independent → one point of intersection
Infinite Singular, redundant Some equations are duplicates → entire line/plane of solutions
None Singular, contradictory Equations contradict (e.g., 0 = 1) → impossible

Example: Unique Solution

System: a + b = 10, a + 2b = 12

Solution: a = 8, b = 2 ✓

Both equations are satisfied simultaneously.

Three Row Operations

These operations preserve the solution set:

1. Swap rows
Reorder equations (order doesn't matter)
2. Multiply row by non-zero scalar
Scale an equation (R1 ÷ 2, R2 × 3, etc.)
3. Add/subtract multiple of one row to another
Combine equations to eliminate variables (R2 - 2×R1)

Critical Rule

Apply operations to the ENTIRE row including constants. If you forget the constants column, you lose information and can't solve the system.

Example: Eliminate a variable

Original:
5a + b = 17
4a - 3b = 6

R1 ÷ 5:
a + 0.2b = 3.4
4a - 3b = 6

R2 - 4×R1:
a + 0.2b = 3.4
0a - 3.2b = -6.4 → b = 2

Row Echelon Form (REF)

A matrix structure where you can easily read the solution (after back-substitution).

Three Rules

1. Zero rows at bottom
All rows with only zeros come after all non-zero rows
2. Each row has a pivot
Leftmost non-zero entry in each non-zero row
3. Staircase pattern
Each pivot is strictly to the right of all pivots above it

Critical: Diagonal Rule

Reading the diagonal left-to-right: Once you hit a ZERO on the diagonal, all diagonal entries to its right must also be ZERO.

Reduced Row Echelon Form (RREF)

RREF = REF + two conditions: pivots = 1, zeros above pivots

Why RREF Matters

REF: Multiple valid REFs, still needs back-substitution

RREF: Exactly one per matrix, solution reads directly

Algorithm: REF → RREF

Phase 1: Make all pivots = 1
Divide each non-zero row by its pivot value
Phase 2: Eliminate above pivots (bottom to top)
For each pivot, make all entries above it = 0

Handling Singular Systems

When you reach a row of ALL zeros in coefficients:

Row: [0, 0, ..., 0 | 0]
Infinite solutions — equation 0=0 is always true
Row: [0, 0, ..., 0 | k] (k ≠ 0)
No solution — equation 0=k is impossible

ML Applications & Debugging

You won't hand-solve systems in ML, but Gaussian Elimination powers every regression model internally.

1. Linear Regression: Normal Equations

Problem: Find weights β
Normal equation: (X^T X)β = X^T y
Internally: np.linalg.solve() uses Gaussian Elimination

2. Multicollinearity Detection

❌ Error: Singular matrix
Cause: Features are linearly dependent (Feature 2 = 2 × Feature 1)
Check rank: np.linalg.matrix_rank(X)
Fix: Remove correlated features or use Ridge Regression

3. Matrix Invertibility

❌ Error: np.linalg.inv() fails
Cause: Matrix A is singular (det = 0)
Why: Gaussian Elimination detects row of zeros = no inverse
Fix: Use np.linalg.lstsq() for overdetermined systems

4. Ill-Conditioning (Numerical Instability)

⚠ Warning: Tiny pivots → huge errors
Cause: Matrix is nearly singular (close to losing independence)
Check: cond_number = np.linalg.cond(A) (should be < 1e10)
Fix: Regularization (Ridge), scale features, center data

5. Infinite Solutions Problem

⚠ Warning: Multiple optimal weights
Cause: Feature matrix is singular (rank < n_features)
Consequence: Many weight vectors minimize loss equally
Fix: Add regularization λI to make matrix non-singular

Quick Debugging Flowchart

❌ Singular matrix error?
├─ Check rank: np.linalg.matrix_rank(X)
│ → rank < n? Multicollinearity detected
│ → Remove features or regularize
├─ Check det: np.linalg.det(A)
│ → det ≈ 0? Matrix singular
│ → Use lstsq() instead of solve()
└─ Check condition number: np.linalg.cond(A)
→ > 1e10? Ill-conditioned
→ Use Ridge Regression

Key Takeaway

Understanding Gaussian Elimination tells you why your model breaks. A singular matrix error isn't random—it means your feature matrix lost independence, and you need to fix your data or algorithm, not just catch an exception.
